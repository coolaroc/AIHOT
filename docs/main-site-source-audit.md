# 主站编辑源接入核验

核验日期为 2026-11-11。线上只读样本采于北京时间约 18:09，使用同一批响应对比旧配置等价映射与新配置。没有开启采集、模型或推送，也没有把线上样本导入本地内容库。

## 字段和来源边界

| 项目 | 当前处理 |
|---|---|
| 人工快讯标识 | 逐条要求 `source === "manual"`，不凭请求 URL 的 `source=manual` 判断；缺失、其他类型、自动聚合值均丢弃 |
| 摘要 | 仅取 `summary`，写入 excerpt，不将摘要标记为完成正文 |
| 快讯正文 | 独立读取 `plain_text`，生成安全 HTML 与正文文本 |
| 头条正文 | 列表没有完整正文，保持 pending，沿现有提取流程读取正确原文页 |
| 头条地址 | `/news/articles/{id}`，原 `/fxs/news/{id}` 不再使用 |
| 上游精选授权 | 仅站点模块明确列出的 `feixiaohao-flash`、`feixiaohao-article`，且当前参与模式为 editorial |
| 不授予授权的字段 | T1、first_party、owner_entity_id、名称和 ID 前缀均不构成精选白名单 |
| 本站更正 | 人工撤选、撤稿、摘要保留和隔离继续生效，不伪造模型高分；普通源仍需完成归组和增量价值判断 |

## 同批线上样本对比

| 项目 | 旧配置等价映射 | 新配置 |
|---|---|---|
| 快讯 50 条 | 收入 50 条，其中 49 条为 jinse 自动聚合 | 仅收入 1 条 manual，其余 49 条剔除 |
| 人工快讯样本 | 摘要被当正文 | 180 字摘要与 197 字正文分别保留，正文有可阅读 HTML |
| 头条列表 52 条 | 其中 35 条非空摘要被标记为完成正文 | 52 条均等待真实正文，不冒充全文 |
| 头条样本 1885 地址 | `/fxs/news/1885` 返回 404 | `/news/articles/1885` 返回 200 |
| 头条样本 1885 内容 | 列表摘要 271 字 | 现有 Readability 流程从原页读到 5234 字，不使用付费兜底 |

这是当时响应的样本结果，不代表主站以后每批数据都有相同数量。上游的人工筛选参数当时未实际隔离自动聚合数据，本地校验仍有必要。

## 种子与数据库

种子基线现为 112 个源，包含现有 34 个 RSS、76 个 X 源和两个主站 JSON 源，移除了旧 AI 示范源。seed 实际新增 2 个，原有 110 个的配置、级别、授权、标签、启用状态和频率逐项保持不变；随后对所有 112 个源核对了种子支持字段与数据库的一致性。

本地内容库仍为 0 篇。`.env` 未修改，采集、模型和外发开关保持关闭。没有新增数据库迁移或删除使用者数据。

## 对外读取

接口版本为 4.1.0。新增 `window=all` 历史检索、`/api/v1/items/{id}` 单篇 JSON、`/api/v1/agent/items/{id}` Markdown，以及 MCP `feixiaohao_get_item`。搜索返回的 ID 可直接用于取内容。摘要、授权正文、语言和完整性分别返回。

正文要求当前来源同时允许站内全文与全文再分发，权限撤销后不再返回正文。三种单篇出口共用公开读取层；撤稿与隔离返回不存在。现有精选 snapshot/changes 继续承担精选副本的更正与移除同步。

接入步骤、分页、缓存与错误处理见 [AI 接入](ai-integration.md)。OpenAPI、llms.txt、Agent 指南和前端接入页已同步。
